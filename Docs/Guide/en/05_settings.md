# Settings Scene Reference

MacStash provides a comprehensive 7-tab configuration window compliant with macOS Human Interface Guidelines. Open using Command+, or via the menu bar icon.

## Tab Directory

1. **General**:
   Master switch, menu bar icon toggle, language switcher (English, Vietnamese), launch at login, and permissions status dashboard for Accessibility, Input Monitoring, and Notifications.

2. **Hot Corners**:
   Per-corner enable toggles, action assignments (Volume, Brightness, Backlight, Pomodoro, None), hit-zone sensitivity (1-20pt), dwell activation delay (0-1000ms), auto-hide delay (50-1000ms), mouse drag suppression, fullscreen suppression, and excluded applications.

3. **Appearance**:
   Dial radius (110-200pt), glass opacity (30-100%), theme selection (System, Light, Dark), animation speed, Reduce Motion support, mechanical audio click sounds, and trackpad haptic intensity.

4. **Displays**:
   Active display inventory with UUIDs, method selector (Auto, DDC/CI, Software Dimming, Native), fallback status explanation, live brightness testing sliders, and hardware clamp limits.

5. **Pomodoro**:
   Focus duration, short break duration, long break duration, rounds before long break, auto-start breaks, and completion chime alerts.

6. **Shortcuts**:
   Global hotkeys for toggling dials and hidden dock, with automated conflict analysis against macOS system reserved combinations.

7. **About / Advanced**:
   Version information, Console log viewer launcher, user manual link, JSON backup export and import, and factory reset.
