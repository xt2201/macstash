# Shortcuts Quick Reference

MacStash integrates system-wide hotkeys and standard window navigation shortcuts.

## Default Key Combinations

| Action | Shortcut | Scope | Description |
|---|---|---|---|
| Open Settings | Command+, | Global / App | Reveals the 7-tab Settings preferences window. |
| Close Window | Command+W | Window | Closes frontmost MacStash window. |
| Open User Guide | Command+? | Global / App | Launches offline Help Viewer window. |
| Toggle Corner Dials | Option+S | Global | Instantly reveals or dismisses active corner dials. |
| Toggle Hidden Dock | Option+D | Global | Slides out or hides the pinned applications shelf. |
| Hide MacStash | Command+H | App | Standard macOS application hide shortcut. |
| Quit MacStash | Command+Q | App | Terminates MacStash and restores original color sync tables. |
