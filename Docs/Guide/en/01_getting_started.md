# Getting Started with MacStash

MacStash provides tactile radial dial controls, configurable edge sliders, temporary file/note drawers, and a widget-powered Second Dock across your macOS displays.

## Core Concepts

MacStash remains unobtrusive until summoned, using low-overhead event tracking and non-activating Liquid Glass panels so focus stays in your active app.

### The Four Physical Corners
1. **Top-Left**: Configured by default for Keyboard Backlight adjustment.
2. **Top-Right**: Configured by default for Display Brightness control.
3. **Bottom-Left**: Configured by default for Pomodoro and Focus Timer.
4. **Bottom-Right**: Configured by default for Master Audio Volume.

### Outer Corners vs Inner Display Junctions
On multi-monitor setups, MacStash can restrict triggers to true outer desktop boundaries (`Trigger only outer desktop corners`) so moving the pointer smoothly between adjacent monitors is never interrupted.

### Configurable Left / Right Edge Sliders & Media Bar
Move your pointer to the configured vertical screen edge (**Left Edge** or **Right Edge**, configurable in Settings > Hot Corners) to reveal a compact vertical slider with quick-toggle icon buttons, album artwork, equalizer bars, and vertical Previous / Play-Pause / Next controls when audio is active. Hovering over the album artwork morphs the bar into a Dynamic Island audio controller where vertical two-finger trackpad swipes scrub playback smoothly without changing system volume; hover the outer-edge Volume button to drop down the dedicated vertical volume bar.

### Stash Shelf, Scratchpad & Cursor Palette
- **Stash Shelf**: Wiggle or shake your mouse while dragging files from Finder, or press `Control+Option+S` (or hover its configured drawer edge) to drop, search, preview, copy, or batch-drag files, links, and snippets.
- **Quick Scratchpad**: Press `Control+Option+N` (or switch tabs inside the edge drawer) to capture instant notes, OTP codes, and prompts, or send notes directly to Stash Shelf.
- **Cursor Radial Palette**: Press `Option+Space` anywhere to summon a four-sector dial right beneath the cursor (Brightness, Volume, Timer, Keep Awake). Hover any sector and scroll to scrub, or click to toggle.

### Second Dock & 16 Live Widgets
MacStash includes an independent **Second Dock** (`Control+Option+D`) supporting pinned applications, running app indicators, folder stacks, multi-profile workspaces (`Command+1..8`), and 16 configurable live widgets (Clock, Date, Weather, System Stats, Calendar, Reminders, Pomodoro, Now Playing, Search, Clipboard, Quick Note, File Shelf, Screenshot, Color Picker, Unit Converter, Bookmarks).

## Brand Identity & Menu Bar Control Center

MacStash features the **Radial Corner Bloom** icon with adaptive light/dark rendering and a structured Menu Bar Control Center popover (`296pt` card layout):
- **Pomodoro & Active Context Cards**: Live countdown display, mode pill, active frontmost app badge, and Keep Awake quick duration selector.
- **Cached Display Brightness & Audio Controls**: Instant sliders for every attached monitor, master output volume, speaker device routing, and keyboard backlight.
- **6 Quick Module Toggles**: Toggle Corner Dials, Edge Slider, Second Dock, Keep Awake, Stash Shelf, or Quick Scratchpad with one click, plus direct shortcuts to Settings (`Command+,`) and User Guide (`Command+?`).
