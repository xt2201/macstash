# Keyboard Shortcuts and Gestures

## Configurable Global Hotkeys

You can record custom global hotkeys in Settings (`Command+,`) > **Shortcuts**:

| Default Shortcut | Action | Description |
| --- | --- | --- |
| `Option+S` | Toggle Corner Dials | Immediately enable or pause active corner dials across all displays |
| `Option+Space` | Cursor Radial Palette | Bloom the 4-sector radial palette directly beneath your cursor |
| `Control+Option+S` | Stash Drop Shelf | Slide out or dismiss the temporary file/link drop shelf |
| `Control+Option+N` | Quick Scratchpad | Slide out or dismiss your persistent quick scratchpad notes |

## Built-In Application & Second Dock Shortcuts

| Shortcut | Action |
| --- | --- |
| `Control+Option+D` | Show or hide the Second Dock |
| `Command+1` .. `Command+8` | Switch active Second Dock profile |
| `Command+,` | Open MacStash Settings window |
| `Command+?` | Open MacStash User Guide window |
| `Command+W` | Close active MacStash window |
| `Command+Q` | Quit MacStash |
| `Esc` | Dismiss active Cursor Palette, Stash Shelf, or Scratchpad overlay |

## Trackpad and Mouse Gestures

- **Two-Finger Scroll / Mouse Wheel**: Glide two fingers on trackpad (with natural inertial momentum filtering) or roll mouse wheel inside an open corner dial, vertical edge slider, or Cursor Palette sector to adjust smoothly.
- **Click-and-Drag Arc Scrubbing**: Press and drag directly inside a dial band or edge track for fine positional tracking with trackpad haptic detents.
- **Drag-Shake Summon**: While dragging files or URLs in Finder or browsers, wiggle or shake the cursor quickly to slide out the Stash Drop Shelf.
- **Center Hub Toggle**: Tap the center badge on any corner dial or the top button on an edge slider to toggle Play/Pause, Mute, Keyboard Backlight, or Keep Awake.
